Мод содержит элементы из следующих сезонов: Новое Поколение, Игра Бога, Идеальный Мир, Голос Времени и Тринадцать Огней. В моде присутствуют измерение Лололошки, Клык Ронаса, Молот Монту, все виды скинтов и способы их получения, фрагменты Скрижалей и всё, что с ними связано, одежда гильдий, маски Тоифэтуна, посохи персонажей, сами персонажи, волшебная палочка и меч путешественника.
